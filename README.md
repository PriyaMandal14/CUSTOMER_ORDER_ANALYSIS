Customer Order Analysis Report 

• Summary 
This report presents a comprehensive analysis of customer orders using Python’s built-in data 
structures. The goal is to classify customers by spending behavior, evaluate product category 
performance, and extract actionable business insights. The analysis leverages lists, tuples, dictionaries, 
and sets to process real-world e-commerce data, enabling data-driven decisions in marketing and 
inventory management. 
•  Data Overview 
• Customers Analyzed: 4 (Priya, Raja, Aashu, Divs) 
• Total Orders: 8 
• Product Categories: Electronics, Clothing, Home Essentials 
• Data Structures Used: 
o Lists: Customer names and order records 
o Tuples: Individual order details 
o Dictionaries: Customer order mapping, category revenue, product classification 
o Sets: Unique products, categories, and customer segments
